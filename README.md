# MPP：驾驶场景视频理解与反馈蒸馏

基于 [MPP-LLaVA / MPP-Qwen-Next](https://github.com/Coobiw/MPP-LLaVA) 的驾驶场景视频问答项目。模型接收按时间排列的视频帧和自然语言问题，生成关于交通参与者、车辆动作、场景变化及驾驶决策的文本回答。

项目围绕领域数据处理、多模态监督微调、反馈蒸馏和错误分析组织训练与评测流程，复用 EVA 视觉编码器、Q-Former 和 Qwen 语言模型，并提供可独立运行的实验入口。

## 核心内容

- **视频数据与视觉缓存**：整理 LingoQA 问答和帧序列，按视频片段划分训练与开发数据；缓存视觉特征，供同一片段的不同问题复用。
- **多模态监督微调**：支持语言模型 LoRA、视觉投影层训练、Q-Former 微调，以及问题条件化的视觉特征提取。
- **反馈驱动的后训练**：在学生当前生成轨迹上进行教师蒸馏，通过参考答案与 Judge 筛选反馈，结合 JSD / KL 目标和原始监督学习；保留教师门控、监督对照与样本诊断。
- **视觉证据探索**：包含局部区域视图、问题相关证据检索，以及教师答案离线迁移的实验代码。
- **训练与评测工程**：提供多卡启动、梯度累积、检查点恢复、问答生成、文本 Judge 评估和逐样本错误分析工具。

## 代码结构

```text
mpp_video_qa/  模型封装、视觉桥接、数据协议和蒸馏目标
scripts/       数据准备、特征缓存、训练、推理与分析入口
configs/       环境和运行依赖
requirements/  独立教师模型的环境依赖
patches/       固定版本的 MPP-LLaVA 加载与生成适配补丁
tests/         数据、模型接口、蒸馏和训练状态的测试
docs/          使用说明、技术记录和实验过程文档
```

环境安装、模型准备和运行命令见 [使用说明](docs/usage.md)。数据、权重、缓存及训练输出通过独立的数据目录管理。上游源码由安装脚本按固定版本获取。

## 项目基础

模型底座来自 [MPP-LLaVA](https://github.com/Coobiw/MPP-LLaVA)，驾驶视频问答数据与 Judge 来自 [LingoQA](https://github.com/wayveai/LingoQA)。可选教师实验使用 [Qwen-Drive](https://github.com/QwenLM/Qwen-Drive-1.0)。依赖来源与相关许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。
